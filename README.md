# My Dotfiles

My research environment (Kitty + Zathura + Neovim).

## Quick Start on a New Laptop

1. **Install Dependencies (Fedora example):**

   ```bash
   sudo dnf install git kitty zathura nvim python python3-neovim texlive-scheme-full
   
2. **Clone and Setup:**

   ```bash
   git clone [https://github.com/GaeSammartino/dotfiles.git](https://github.com/GaeSammartino/dotfiles.git) ~/dotfiles
   cd ~/dotfiles
   ./setup.sh
